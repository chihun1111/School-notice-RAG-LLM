## IT 분야 주제 적합성

- **AI 기반 웹 서비스 제작**: Streamlit 웹 챗봇 프로토타입 구현
- **챗봇 설계**: 자연어 질문 → 관련 공지 검색 → 근거 기반 답변 흐름 구현
- **데이터 분석 시스템 구축**: 공지/학사일정 CSV·JSONL 데이터셋 생성 및 검색 점수화
- **UI/UX 개선 프로젝트**: 추천 질문, 데이터셋 상태, 출처 카드, 안전 응답 표시

## 제출 전 보강 우선순위

1. PPT 10분 발표 흐름 작성
2. 실제 시연 화면 캡처 추가
3. 검증 명령 실행 결과를 결과보고서에 기입
4. 팀원 이름/역할/학과 등 인적 정보 입력
5. 최종 제출 파일명 통일
